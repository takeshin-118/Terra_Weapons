# Terracraft 設定編集ガイド

## 仮IDの変更

正式ワールドを開始する前に `TerracraftMod.java` の `nether_axe` と `altar_core` の登録IDを変更します。同じIDを使用するレシピ、翻訳、構造JSONも更新してください。ワールド運用後の変更は既存アイテム・ブロックを別IDとして扱うため、データ移行が必要です。

## 祭壇構造テンプレート

初回起動時に、同梱テンプレート `src/main/resources/data/terracraft/defaults/nether_axe_altar.json` が実行環境の `config/terracraft/nether_axe_altar.json` へコピーされます。以後は外部側のJSONを編集してください。層ごとの文字図、文字とブロックIDまたはブロックタグの対応、供物を定義します。ネザー斧の標準構造は5×5×2で、回転のみを許可し、左右反転は許可しません。

記号の対応表では、単一ブロックには `"block": "minecraft:..."`、タグには `"tag": "minecraft:..."` を使います。タグが空の場合は構造が一致しませんが、再読込自体は安全に完了します。

供物も同様に、各要素へ `"item": "minecraft:..."` または `"tag": "minecraft:..."` のどちらか一方を指定できます。たとえば `{ "tag": "minecraft:planks", "count": 16 }` のように書くと、そのアイテムタグに属するアイテムを供物にできます。

ブロック状態も固定したい場合は `properties` を追加します。たとえば柱の向きを限定するなら、`"properties": { "axis": "y" }` のように記述します。指定されたプロパティが存在しない、または値が一致しないブロックは構造に一致しません。

編集後は、権限レベル3以上で次を実行します。

```text
/terracraft config reload
```

必須キー・ブロックID・層サイズ・上段の空気指定が不正な場合、再読込は失敗します。その場合に現在有効な正常設定は置き換えられません。再読込成功時は安全のため一括破壊キューと進行中の儀式を中止します。

現在のテンプレートでは `.` は空気必須、`A` は祭壇コアです。上段は `..A..` の中心だけがコアで、残りの行はすべて `.....` である必要があります。

## 一括破壊

初回起動時に `config/terracraft/tree_felling.json` が作成されます。`max_logs`（1〜512）、`max_foliage`（0〜2048）、`per_task_per_tick`（1〜128）、`global_per_tick`（1〜256）、`max_tasks`（1〜64）、`max_tasks_per_player`（1〜16）で安全上限と処理量を調整できます。

`include_vines`、`include_cocoa`、`include_nether_foliage` はそれぞれ、つる・ココア・ネザーのウォートブロック／菌糸の光／ネザーつるを対象に含めるかを切り替えます。設定変更後は `/terracraft config reload` を実行してください。範囲外の数値がある場合は、直前の正常な設定を維持します。

## アセット差し替え

仮モデル・テクスチャ・GeckoLibアニメーションは `assets/terracraft/` 配下に置きます。祭壇用のbone名は `core`、アニメーション名は `activate`、`idle`、`ritual`、`deactivate` を予約します。
