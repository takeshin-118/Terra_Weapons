# Terra_Weapons（Terracraft）

祭壇の儀式で武器の権利を獲得し、携帯レシピから専用武器を作成する Minecraft Java 1.21.11 / Fabric 用MODです。武器・祭壇・携帯レシピを1本のJARにまとめています。現在の対応武器はテラオノです。

## この版のJEI連携

JEI 27.35.0.90（Minecraft 1.21.11）を導入すると、テラオノのレシピに権利アイコンを表示します。未取得時は灰色の鍵が付き、取得済みなら鍵を隠します。クリックすると、祭壇の配置を確認できる3D儀式ページへ移動します。「全体／床」「回転／停止」を切り替えられ、ブロックからレシピを開けます。権利アイテム自体にクラフトや使用効果はありません。

操作設定の「Terracraft → 携帯レシピを開く」で初期キーHを変更できます。権利コマンドの武器IDはTabで terra_axe を補完できます。旧名nether_axeで保存された権利も引き継ぎます。

## 主な機能

- **テラオノと一括伐採**：権利を持つプレイヤーが原木を壊すと、つながった原木などを上限付きで順次処理します。スニーク中は一括伐採を行いません。
- **祭壇と儀式**：5×5の床と祭壇コアからなる構造を組み、供物を捧げてテラオノの権利を獲得します。完成した祭壇コアを右クリックすると奉納画面を開けます。
- **携帯レシピ**：`H`キーで書棚を開き、テラオノの設計書から素材の所持数・権利の取得状況を確認して作成します。初期キーは操作設定から変更できます。
- **祭壇コアの携帯作成**：テラオノをメインハンドに持ち、スニークしながら右クリックすると作成画面を開きます。汎用の3×3作業台ではなく、祭壇コア用の作成画面です。
- **プレイヤーごとの権利管理**：権利はUUID単位でワールドに保存します。斧を他人へ渡しても権利は移りません。権利のない所持者には攻撃性能の制限がかかります。
- **サーバー設定**：祭壇の構造・供物や一括伐採の対象・処理上限をJSONで調整できます。
- **エンチャント**：バニラの斧用エンチャントに加え、火属性IIまで対応します。エンチャント台・金床・砥石は権利所有者が利用でき、金床は追加倍率なし・最大64レベルです。テラオノ同士の合成は禁止します。詳しくは[エンチャント仕様](docs/terra-axe-enchantments.md)を参照してください。

権利のないプレイヤーには、呪いを含むテラオノのエンチャント効果を適用しません。付与内容は保持され、権利所有者が使うと再び有効になります。クリエイティブは権利チェックを免除します。一括伐採は原木のみ耐久値を消費し、追加処理は残り耐久値1で停止します。直接の採掘・攻撃では通常どおり壊れます。

携帯レシピの権利確認、素材消費、完成品の付与はサーバー側で処理します。受け取る空きがない場合は素材を消費しません。素材を使い切って空いた通常スロットにも完成品を受け取れます。

## 動作環境・導入

| 項目 | 対応・必要バージョン |
| --- | --- |
| Minecraft Java | 1.21.11 |
| Java | 21以上（ビルドにはJDKが必要） |
| Fabric Loader | 0.18.1以上 |
| Fabric API | ビルド・検証版：0.141.6+1.21.11 |
| GeckoLib | 1.21.11用の5.4.2以上 |

サーバーと参加する全クライアントの `mods` フォルダーに、依存MODと `terracraft-0.1.4.jar` を配置します。旧バージョンのJARは外し、`-sources.jar` は開発用なので導入しません。

### 旧2本構成からの移行

1. 旧本体JARを統合版 `terracraft-0.1.4.jar` に差し替えます。
2. 旧 `terracraft-portable-recipe-ui-*.jar` を `mods` フォルダーから外します。
3. サーバーとクライアントの両方を統合版に揃えて起動します。

旧追加MODとの同時導入は、登録の重複を防ぐためFabric Loaderが拒否します。MOD ID `terracraft`、アイテム・ブロックID、権利データ、携帯レシピのキー設定は維持しています。`terracraft_portable_recipe_ui` は素材・通信・キー設定の互換用名前空間として残り、独立したMODとしては読み込みません。

## レシピと設定

- テラオノ：ネザライトインゴット×3、ブレイズロッド×2、テラオノの権利。
- 祭壇コア：ダイヤモンドブロック×4、泣く黒曜石×4、ネザースター×1。
- 儀式の標準供物：ネザライトインゴット×2、ブレイズロッド×16、マグマクリーム×16、泣く黒曜石×8、ネザースター×1。

儀式の供物と武器作成の素材は別です。初回起動時に `config/terracraft/` へ設定ファイルを生成します。構造・供物・伐採設定の変更方法は[設定編集ガイド](terracraft/docs/設定編集ガイド.md)を参照してください。

## 管理者コマンド

権限レベル3以上で実行します。

```text
/terracraft weapon permission grant <player> terra_axe
/terracraft weapon permission revoke <player> terra_axe
/terracraft weapon permission check <player> terra_axe
/terracraft weapon permission list <player>
/terracraft config reload
```

付与・剥奪ではプレイヤー名の代わりにUUIDも指定できます。

## 開発・検証

Java 21のJDKを設定し、リポジトリのルートで実行します。

```powershell
.\gradlew.bat clean build
```

Linux/macOSでは `./gradlew clean build` を実行します。成果物は `build/libs/terracraft-0.1.4.jar` です。ビルド時に携帯レシピの素材消費・空きスロット判定の回帰テストも実行します。

- `src/main/`：武器・祭壇・権利管理・携帯作成のサーバー処理と素材。
- `src/client/`：祭壇・携帯作成・携帯レシピの画面。
- `src/test/`：回帰テスト。
- `terracraft/docs/`：設定編集ガイド。旧サブプロジェクトの個別ビルドは廃止済みです。
