# テラオノの権利取得アイテム
- ID: terracraft:terra_axe_permission
- 標準ネザースターの形を維持し、外側を赤茶、明るい部分をオレンジ、中央を黄色に変更。
- テクスチャ: src/main/resources/assets/terracraft/textures/item/terra_axe_permission.png
- モデル: minecraft:item/generated
- 表示専用。所持・使用による権利付与やクラフトレシピはありません。
- JEIのテラオノのレシピには未取得時のみ灰色の鍵を表示。クリックで3D儀式ガイドへ移動。
- 儀式ガイドの幾何計算は tools/RitualProjectionCheck.java で検証できます。
