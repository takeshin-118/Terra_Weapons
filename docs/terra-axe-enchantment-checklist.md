# テラオノのエンチャント：ゲーム内確認チェックリスト

対象仕様：[テラオノのエンチャント仕様](terra-axe-enchantments.md)

作成・確認日：2026-10-03。ユーザーから全確認項目通過の報告を受け、手動確認29項目を完了として記録しました。画面表示を含むゲーム内確認はユーザーによる確認結果です。自動検証ではビルド・JUnit 6件・Minecraft GameTest 12件が成功しています。

手動確認時のJAR名は `terracraft-0.1.2.jar` です。確認済みの実装を正式版 `0.1.3` としてビルドし、以降の導入には `terracraft-0.1.3.jar` を使用します。

## 準備

- [x] サーバーとクライアントの両方に今回ビルドした `terracraft-0.1.2.jar` を配置し、再起動する。同じバージョン名の旧JARと取り違えない。
- [x] 検証用ワールドに、エンチャント台＋本棚、金床、砥石、作業台、クラフターを用意する。
- [x] テラオノ数本、比較用ネザライトの斧、ネザライトインゴット、ラピスラズリ、各種エンチャント本を用意する。
- [x] クリエイティブによる準備後、権利の確認は必ずサバイバルで行う。耐久力なし・修繕なしの斧も残す。
- [x] 詳細ツールチップを `F3＋H` で有効にし、耐久値を確認できるようにする。

管理者権限で使うコマンド。チャットの `@s` は実行者自身です。コンソールから実行する場合や、画面を開いたまま別の管理者が操作する場合は、対象プレイヤー名に置き換えます。

```text
/terracraft weapon permission grant <プレイヤー名> terra_axe
/terracraft weapon permission revoke <プレイヤー名> terra_axe
/terracraft weapon permission check <プレイヤー名> terra_axe
/gamemode survival
/gamemode creative
/experience set @s 64 levels
```

境界値確認用の斧は以下で準備できます。エンチャントを付けずに使います。

```text
# 金床の高額修理用：耐久を1000消費、修理履歴コスト100
/give @s terracraft:terra_axe[minecraft:damage=1000,minecraft:repair_cost=100]

# 一括伐採の停止用：最大耐久4062のうち残り2
/give @s terracraft:terra_axe[minecraft:damage=4060]
```

## まず確認する8項目

- [x] **01 エンチャント台をクリックできる**：権利あり・十分な経験値とラピスでテラオノを入れ、候補をクリックする。→ 実際に付与され、表示だけの成功にならない。所定の経験値・ラピスが消費される。
- [x] **02 火属性の本が使える**：新品のテラオノ＋火属性IIだけの本を金床に入れる。→ 火属性IIの結果が出る。履歴なし・名前変更なしなら4レベルで、1.3倍の追加料金がない。
- [x] **03 64レベルで加工できる**：高額修理用の斧＋ネザライトインゴット1個を金床に入れる。→ 「コストが高すぎます」ではなく64レベルと表示。所持63では受け取れず、64では受け取れ、受け取り後は0レベルになる。
- [x] **04 権利不足の表示**：権利を剥奪し、テラオノをエンチャント台・金床・砥石へ順に入れる。→ 各画面に「テラオノの権利が必要です」。加工できず、経験値・素材・斧を失わない。入力した斧は取り出せる。
- [x] **05 合成禁止の表示**：権利ありで、金床・砥石へテラオノを2本入れる。→ 「硬すぎてくっつかない」と表示され、結果は受け取れない。両方の斧が残る。
- [x] **06 砥石で除去できる**：通常のエンチャントと消滅の呪いを付けた斧を、権利ありで砥石に1本入れる。→ 通常のエンチャントだけ消え、消滅の呪いは残る。
- [x] **07 原木だけ耐久消費**：耐久力・修繕なしの斧で、つながった原木3個と自然扱いの葉を一括伐採する。→ 全原木・対象の葉が壊れ、耐久消費は最初の原木を含めて3。葉の分は消費しない。手置きの葉は対象外なので、育てた木かコマンドで自然扱いにした葉を使う。
- [x] **08 最後の耐久を保護**：残り耐久2の斧で、つながった原木を一括伐採する。→ 最初の1個を壊して残り1になり、追加伐採は停止。残った原木をスニークして直接壊すと、斧は通常どおり壊れる。

## 付与・金床・砥石の追加確認

- [x] **09 エンチャント台の火属性**：権利ありで候補を更新しながら複数回付与する。→ 火属性IまたはIIが付くことがある。候補の表示だけでなく、付与後の内容も確認する。抽選なので、数回出ないだけで不具合と判断しない。候補入りとIIの条件は自動テストでも検証済み。
- [x] **10 最大レベルと競合**：火属性IIの斧へ火属性IIの本、幸運の斧へシルクタッチの本、ダメージ増加の斧へアンデッド特効の本を試す。→ 火属性IIIにならず、競合エンチャントも同時に付かない。単独でドロップ増加の本を試しても付与できない。クリエイティブではなくサバイバルで確認する。
- [x] **11 修理・名前変更**：権利ありでネザライト修理と名前変更をそれぞれ実行する。→ 耐久が回復し、指定した名前が付く。既存エンチャントは保持される。権利なしでは両方とも拒否される。
- [x] **12 受け取り方法**：金床・砥石の正常な加工を通常クリックとShiftクリックで試す。→ 成果物は1個だけ受け取れ、素材と経験値の処理も1回分。権利不足・合成禁止の状態では、どちらの操作でも受け取れない。
- [x] **13 砥石の入力欄**：エンチャント済みの斧を上側・下側の入力欄へ1本ずつ入れて除去する。→ どちらでも同じ結果。通常エンチャント除去時の経験値が発生する。呪いだけを再投入しても通常エンチャント分の経験値を繰り返し得られない。
- [x] **14 クラフト修理の禁止**：作業台・インベントリのクラフト欄・クラフターでテラオノ2本の修理を試す。→ 完成品が出ず、入力の斧も消費しない。「硬すぎてくっつかない」の表示必須箇所は金床・砥石。
- [x] **15 バニラ道具への影響**：普通のネザライトの斧を金床・砥石・クラフト修理に使う。→ 通常の加工が可能で、高額な金床加工にはバニラの「コストが高すぎます」が残る。

## 権利とエンチャント効果

以下は同じ斧で「権利あり → 剥奪 → 再付与」を比較します。剥奪中もツールチップからエンチャントが消えないことを確認します。

- [x] **16 火属性**：炎に耐性がなく、すでに燃えていない同種の敵へ攻撃する。→ 権利ありでは着火し、権利なしでは着火しない。再付与で着火するようになる。
- [x] **17 効率強化**：効率強化Vの斧を持ったまま権利を変え、同じ種類の原木をスニークして直接採掘する。→ 権利なしでは速度上昇が消え、再付与すると復帰する。持ち替え・再ログインが必要にならない。
- [x] **18 耐久力**：耐久力III・修繕なしの斧で、同数の原木をまとめて直接採掘する。→ 権利なしでは原木1個につき耐久1消費。権利ありでは確率で消費が軽減される。少数回の偶然だけで失敗としない。
- [x] **19 修繕**：消耗した修繕付きの斧をメインハンド、次にオフハンドへ持ち、経験値オーブを取る。→ 権利ありでは修理され、権利なしでは修理されず経験値として受け取る。他の修繕装備は外して比較する。
- [x] **20 シルクタッチ**：シルクタッチ付きの斧で葉を直接破壊し、次に一括伐採の追加処理で葉を壊す。→ 権利ありでは葉ブロックが出る。権利なしでは直接破壊で葉ブロックが出ず、一括伐採も発動しない。
- [x] **21 幸運**：シルクタッチと別の斧に幸運IIIを付け、葉などの幸運が有効な対象を十分な数で比較する。→ 権利ありの直接破壊・一括伐採に幸運が反映され、権利なしでは反映されない。原木そのものの個数増加は期待しない。1本の木だけで確率差を判定しない。
- [x] **22 消滅の呪い**：検証用ワールドでアイテムを死亡時に落とす設定にし、消滅の呪い付きの斧を所持して死亡する。→ 権利ありでは斧が消滅し、権利なしでは落ちて回収できる。回収後も呪いの付与内容は残る。
- [x] **23 クリエイティブ免除**：権利なしのクリエイティブで加工と火属性を確認する。→ エンチャント台・金床・砥石を利用でき、火属性も有効。ただしテラオノ2本の合成は引き続き禁止。

## 画面・マルチプレイ・継続処理

- [x] **24 表示の読みやすさ**：GUIスケールを普段の設定と大きめの設定に変え、金床・砥石・エンチャント台を開く。→ エラーメッセージが画面外に切れず、入力欄・名前欄・コスト・ツールチップの操作を妨げない。
- [x] **25 エラーの切り替え**：権利なしで2本を入れ、権利を付与してから1本を取り出す。→ 「テラオノの権利が必要です」→「硬すぎてくっつかない」→エラーなし、の順で切り替わり、古い表示が残らない。
- [x] **26 開いたまま権利変更**：加工可能な入力と結果を表示したまま、別の管理者またはコンソールで権利を剥奪する。→ 閉じ直さずに拒否表示へ変わり、結果を取れない。再付与すると有効な結果・候補が戻る。3種類の加工画面で試す。
- [x] **27 他人への受け渡し**：マルチプレイで、強化済みの同じ斧を権利ありの人から権利なしの人へ渡し、返してもらう。→ 受け手の権利に応じて効果が切り替わり、名前・耐久値・エンチャント内容は保存される。元の持ち主の権利は移らない。
- [x] **28 保存後も維持**：強化済みの斧を持って再ログインし、さらにワールド／サーバーを再起動する。→ エンチャント内容とプレイヤーの権利が保持され、効果の有効・無効も正しい。
- [x] **29 一括伐採の中断**：処理が複数tickかかる大きさの木で、伐採途中に持ち替え・スニーク・権利剥奪・ログアウトを個別に試す。→ 次の処理時に追加伐採が停止し、持ち替え先の道具を消耗しない。処理が一瞬で終わる木では判定しない。
